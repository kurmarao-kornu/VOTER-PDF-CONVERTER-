5. Accuracy and limitations

  • EPIC Number is kept as text and used as the main voter reference. Duplicate EPICs are flagged, never deleted.
  • Repeated voter names are allowed. Each detected voter card becomes a separate row.
  • Original PDF page number and printed electoral-roll page number are recorded separately.
  • This first version reads selectable/searchable Telugu electoral-roll PDFs using the Andhra Pradesh photo-roll labels. Scanned image-only PDFs and unfamiliar layouts are flagged as unsupported rather than silently producing incomplete records.
  • Place/locality is filled only when it can be matched to the section details on the cover page. Otherwise it remains blank for review.
  • OCR/text extraction is not visual proof. Check flagged rows and compare the exported records with the source PDF before official use.
